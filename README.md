# جولة Scopewise

عرض تفاعلي بالعربية من 22 شريحة يشرح منصة [Scopewise](https://a-ayati.github.io/Scopewise/): كل مشروع، من الموجز إلى الدفع، في مكان واحد، بين المستقلين وشركات الإنتاج والقنوات. اللقطات مأخوذة من النسخة الحالية للمنصة.

- صفحة واحدة مستقلة (`index.html`)، الصور مضمّنة داخلها ولا تحتاج إلى أي ملفات أخرى.
- التنقل بالأسهم أو بالسحب على الجوال، والمفتاح `F` يفتح الفهرس.
- يدعم الوضع الفاتح والداكن.

للنشر: Settings → Pages → Deploy from a branch → `main` / root.
